Journey: Demo connect → Keymap → record layer/position/binding → editor → different binding → verify target/dirty → Save → Saved/disabled → application Reload/readback → restore → Save → Reload/readback. Measure first preview, full readiness, editor open, search, edit acknowledgement, and Save separately. Repeat editor and edit/save cycles for latency/resources. Restore language, selector mode, auto advance, close-on-select, OS layout, and changed settings. Modal Close/Escape may apply; floating Close/Escape discards unfinished drafts. Check KM-002/006/007/009, KM-I01/I02, BIND-003/004/005/015, SESSION-002/003/007.

Demo measures frontend/synthetic protocol behavior, not USB/BLE latency, flash time, or power-cycle persistence. Use authorized device or Renode for applicable questions and report Renode transport/ELF limits.
