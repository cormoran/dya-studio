# Pop: クリーミーパステル × ポップ

実装: [pop.css](./pop.css)、[フォント読み込み](./loadPopFont.ts)。共通仕様は [README](./README.md) を参照。

白を混ぜた紙粘土のような、軽く柔らかい発色。**くすませすぎない**ことを重視する。灰色・茶色を混ぜて落ち着かせるのではなく、明るさを保ったパステルの面と、色味を感じる小さなアクセントを組み合わせる。参考画像の配色は方向性として扱い、そのままコピーしない。

アイスブルーのカードを軸にする。画面全体を強い色で塗らず、主要操作はクリアな青、見出しは淡い青、補助操作・変更状態はミント、警告はクリームイエローで役割を分ける。

| 役割                         | 色                         |
| ---------------------------- | -------------------------- |
| 画面の外側・通常キー・入力欄 | 白 `#FFFFFF`               |
| カード                       | アイスブルー `#F2FAFF`     |
| 通常の説明パネル             | 淡い青 `#E4F5FF`           |
| 選択・主要操作               | ミルキースカイ `#65CAFA`   |
| ページ見出しアイコンの背景   | 淡いアイスブルー `#E4F5FF` |
| 選択中のタブ下線             | クリーミーピンク `#FF91A6` |
| 補助操作・変更状態           | ミント `#9EE5BD`           |
| 削除・警告の文字とアイコン   | タブ下線と同じ `#FF91A6`   |
| 警告の背景                   | クリームイエロー `#FFECAD` |
| エラーの背景                 | 淡い赤 `#FFF0EE`           |
| 本文                         | チャコール `#393735`       |

## 調整時に守る点

- 外側の白い背景とアイスブルーのカードを区別する。「背景」を調整するときはどちらを指すか確認し、白いキー・入力欄がカード上で見える色差を保つ。
- 軽さ・柔らかさは白を混ぜたような明るい色面で作る。輪郭を強めるより面の色差と丸みを優先し、灰色・茶色を足して落ち着かせすぎない。参考パレットにある全色を各部品へ配る必要はない。
- primary・activeの基本色は青系を保つ。赤系の主要ボタンは強すぎると判断されており、色数を増やす場合も小面積の差し色と操作の役割を分ける。明るい塗りには濃い文字・アイコン、白地のリンクには濃い同系色を使う。
- カード・通常キー・物理モジュールのプレビュー・見出しアイコン・説明パネルは、枠線ではなく面の色差で見せる。寸法維持のための透明な border は許容する。
- 装飾的な影、発光、ぼかしは追加しない。「ぼやっとした輪郭」はぼかし効果ではなく、通常の枠を目立たせない方針として扱う。丸みと色で柔らかさを出す。
- ページ見出しアイコンは淡い青の面とチャコールのアイコン、通常の説明パネルも淡い青とする。見出しだけのライラックは戻しており、説明を飾るための黄色も使わない。黄色は警告やコンボ位置選択など意味のある用途に残す。
- 入力欄の境界は薄い1px。フォーカスは明るいスカイブルー（#3797C4）の2px outline、offset 1pxで示す。選択・hover・キーボードfocusは分かるように保つ。
- 表示専用の物理モジュールはhoverで色を変えず、詳細tooltipだけを表示する。
- キーマップ保存/共有の浮動メニューは白背景と薄い青の1px枠にし、背後のアイスブルーのカードと区別する。影は使わない。
- エンコーダーのbinding選択ボタンは淡い青（#E4F5FF）、hoverは少し強い青（#D2EEFF）。枠線用の青灰色を背景に流用しない。
- メインタブは背景を塗りつぶさず、選択中の太いクリーミーピンクの下線で示す。現在は単色の下線を青い面に対する差し色とし、オレンジ寄りのコーラルや灰色味の強いピンクより、クリアなピンクを使う。
- 警告・エラーの意味は文字とアイコンでも示す。削除アイコン・warning tokenを使う文字や枠・警告バナーの文字は、タブ下線と同じクリーミーピンク（#FF91A6）に揃える。背景は独立したクリームイエローを使い、ピンクの半透明色へ置き換えない。
- グレーは主に無効状態に使う。通常操作のhoverは同系色を維持する。

診断の状態ラベルはミント・クリームイエロー・淡いコーラルの背景を使う。警告ラベルの文字は共通warning tokenのクリーミーピンク、正常・エラーの文字は濃い同系色を使う。Demo subsystemの項目背景は淡い青、コンボのプレビュー背景はアイスブルーとして白い通常キーの形を見せる。コンボ位置選択は元のテーマの黄色系を引き継ぎ、クリームイエローで示す。青い主要操作へ一律に揃えない。入力ストリームのハイライトは維持する。

接続画面はUSBをスカイブルー、BLEをミント、Demoを鮮やかなクリーミーピンクで色分けする。周囲の3本の円は内側から淡い青・ミント・ピンクとし、操作ボタンより控えめにする。

## 書体

Pop だけ M PLUS Rounded 1c を使用。本文・説明文400、ボタン・通常タブ・ヘッダーロゴ500、見出し・選択中メインタブ700（現行CSSの指定）。入力欄・キー刻印・コードの既存書体は維持する。

フォントは Pop 選択時のみ CDN から非同期で読み込み、待機・失敗時は既存書体で操作を継続する。他テーマでは Pop のフォント定義自体を無効にする。
