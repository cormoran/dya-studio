# Light: 青みのある白と涼しげなアクセント

実装: [index.css](../index.css) の `:root.light` と共有コンポーネントスタイル。共通仕様は [README](./README.md) を参照。

## コンセプト

明るい白い面に、わずかに青みのある背景・文字・境界を合わせる標準のライトテーマ。シアン系の主要操作、緑系の補助操作、紫系のアクセントで役割を示す。Neutralより色味があり、Popより抑えた半透明のアクセント面を使う。

## 代表パレット

| 役割                            | 色                                          |
| ------------------------------- | ------------------------------------------- |
| 画面背景                        | `#F8FAFC`                                   |
| 通常の面 / 一段高い面           | `#FFFFFF` / `#F1F5F9`                       |
| 本文 / 補助 / muted             | `#0F172A` / `#475569` / `#64748B`           |
| 主要アクセント                  | `#007FA5`                                   |
| 補助アクセント                  | `#00866B`                                   |
| cyberアクセント（rootから継承） | `#8B5CF6`                                   |
| warning token                   | `#D97706`                                   |
| 枠 / hover枠                    | `rgba(15,23,42,0.1)` / `rgba(15,23,42,0.2)` |

カードは白の半透明面（opacity 0.8）と薄い枠・控えめな影を使う。主要・補助ボタンは通常時にアクセントを薄く混ぜた面と色付きの文字・枠、hoverで少し強い面と枠を使う。

## 調整時に守る点

- 青みを一律に取り除かない。無彩色の白主体はNeutralの役割。
- 白い面で読む文字・リンクにはライト用の濃いアクセントを使う。Dark用の明るいネオン色をそのまま文字へ流用しない。
- 選択中のメインタブは主要アクセントの文字と2pxの下線。Pop専用のピンクや太い下線を持ち込まない。
- カード・入力・キー・dropdownは薄い境界や面の差で識別できること。透明な面は実際の背後の色も含めて確認する。
- 警告・エラー、選択・変更状態の意味を保つ。装飾を減らすために状態まで無彩色にしない。

## 書体

既存のInter/system系を維持する。見出し・本文・説明・ボタン・ロゴのweightは共通スタイルに従い、Popの丸ゴシックを残さない。コードや等幅ラベルは既存の指定を維持する。
