# Dark: チャコールの面とネオンアクセント

実装: [index.css](../index.css) の `:root` 既定値と共有コンポーネントスタイル。Darkはこの既定値を使う。共通仕様は [README](./README.md) を参照。

## コンセプト

黒に近い背景とチャコールの面に、シアン・ミント・紫の鮮やかな光のようなアクセントを合わせる標準ダークテーマ。面の明度差と半透明の枠で情報を区切り、操作・状態に色を使う。Popの白を混ぜた明るい面とは異なり、暗い面上でアクセントが映える構成。

## 代表パレット

| 役割                  | 色                      |
| --------------------- | ----------------------- |
| 画面背景              | `#0A0A0A`               |
| 通常の面 / 一段高い面 | `#2A2A2A` / `#363636`   |
| 本文                  | `#FFFFFF`               |
| 補助 / muted          | 白のopacity 0.7 / 0.6   |
| 主要アクセント        | `#00D4FF`               |
| 補助アクセント        | `#00FFCC`               |
| cyberアクセント       | `#8B5CF6`               |
| warning token         | `#F59E0B`               |
| 枠 / hover枠          | 白のopacity 0.14 / 0.26 |

カードはチャコールの半透明面（opacity 0.9）。共有スタイルの薄い枠、blur、控えめな影やアクセントのglowを使う。主要・補助ボタンはアクセントを薄く混ぜた面と鮮やかな文字・枠で示す。

## 調整時に守る点

- 背景とカードを同じ黒に潰さず、面の階層を残す。文字・入力・浮動メニューが暗い背景へ溶け込まないこと。
- 鮮やかなアクセントは操作・状態のために使い、広いカード全体をネオン色で塗らない。glowで文字や境界を読みにくくしない。
- 選択中のメインタブはシアンの文字と2pxの下線。Popの太いピンク下線や白いカードを引き継がない。
- mutedやdisabledの透明度は暗い面で実測する。背景が白のテーマで見えたことをDarkの可読性の証拠にしない。
- 警告・エラー・変更状態の意味色と文言・アイコンを維持する。

## 書体

既存のInter/system系とコード等の等幅指定を維持する。暗いテーマだからといってフォント全体を太くしたり、Popの丸ゴシックを適用したりしない。
