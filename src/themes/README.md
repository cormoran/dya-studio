# Theme design

テーマの選択・保存・フォント読み込みの仕様は [SHELL-005](../../docs/spec/modules/app-shell.md) を参照。Pop の実装は [pop.css](./pop.css)、Neutral は [neutral.css](./neutral.css)。追加テーマのスタイルは各テーマの root class 内に限定する。

## Pop: クリーミーパステル × ポップ

白を混ぜた紙粘土のような、軽く柔らかい発色。**くすませすぎない**ことを重視する。灰色・茶色を混ぜて落ち着かせるのではなく、明るさを保ったパステルの面と、色味を感じる小さなアクセントを組み合わせる。参考画像の配色は方向性として扱い、そのままコピーしない。

アイスブルーのカードを軸にする。画面全体を強い色で塗らず、主要操作はクリアな青、見出しは淡い青、補助操作・変更状態はミント、警告はクリームイエローで役割を分ける。

| 役割                         | 色                         |
| ---------------------------- | -------------------------- |
| 画面の外側・通常キー・入力欄 | 白 `#FFFFFF`               |
| カード                       | アイスブルー `#F2FAFF`     |
| 通常の説明パネル             | 淡い青 `#E4F5FF`           |
| 選択・主要操作               | ミルキースカイ `#65CAFA`   |
| ページ見出しアイコンの背景   | 淡いアイスブルー `#E4F5FF` |
| 補助操作・変更状態           | ミント `#9EE5BD`           |
| 警告の背景                   | クリームイエロー `#FFECAD` |
| エラーの背景                 | 淡い赤 `#FFF0EE`           |
| 本文                         | チャコール `#393735`       |

### 輪郭と状態

- カード・通常キー・物理モジュールのプレビュー・見出しアイコン・説明パネルは、枠線ではなく面の色差で見せる。寸法維持のための透明な border は許容する。
- 装飾的な影、発光、ぼかしは追加しない。丸みと色で柔らかさを出す。
- 入力欄の境界は薄い1px。選択・hover・キーボードfocusは分かるように保つ。
- 表示専用の物理モジュールはhoverで色を変えず、詳細tooltipだけを表示する。
- メインタブは背景を塗りつぶさず、選択中の太い青い下線で示す。
- 警告・エラーの意味は文字とアイコンでも示す。濃い警告文字色を半透明にして背景へ流用すると濁るため、明るい背景専用色を使う。
- グレーは主に無効状態に使う。通常操作のhoverは同系色を維持する。

診断の状態ラベルはミント・クリームイエロー・淡いコーラルの背景に濃い同系色の文字を使う。Demo subsystemの項目背景は淡い青、コンボの位置選択はミルキースカイとし、警告や入力ストリームのハイライトと区別する。

### 書体

Pop だけ M PLUS Rounded 1c を使用。本文・説明文400、ボタン・タブ・ヘッダーロゴ500、見出し700。入力欄・キー刻印・コードの既存書体は維持する。

フォントは Pop 選択時のみ CDN から非同期で読み込み、待機・失敗時は既存書体で操作を継続する。他テーマでは Pop のフォント定義自体を無効にする。
