# Neutral: 青みを抜いた白とモノクローム

実装: [neutral.css](./neutral.css)。共通仕様は [README](./README.md) を参照。

## コンセプト

Lightの青みを抜き、白を強めた、特徴を前面に出しすぎないテーマ。グレーを装飾的なテーマカラーとして面に広く塗らず、白い面と文字・細い輪郭で構成する。ページ見出しアイコンやタブに差し色を加えず、落ち着いた無彩色の一貫性を保つ。

## 代表パレット

| 役割                          | 色                                           |
| ----------------------------- | -------------------------------------------- |
| 画面背景                      | `#FAFAFA`                                    |
| 通常の面・カード              | `#FFFFFF`                                    |
| 一段高い面 / 無効操作の面     | `#F5F5F5`                                    |
| 本文・選択の輪郭              | `#171717`                                    |
| 補助 / muted                  | `#525252` / `#666666`                        |
| electric / neon / cyber token | `#404040` / `#525252` / `#595959`            |
| 通常枠 / hover枠              | 黒のopacity 0.1 / 0.2                        |
| warning banner                | 背景 `#FFF4DF`、文字 `#78350F`、枠 `#C9954D` |

## 調整時に守る点

- primary・activeなボタンはhover時も白背景と濃い輪郭で示す。「くっきりした黒枠」は太枠の意味ではない。選択レイヤーやUSB/BLE/Demoの枠は1pxとし、内枠の重複で太くしない。同じスタイルの操作部品にも揃えるが、キーの状態表示等の別用途の線を一括で細くしない。borderのない選択要素は薄いinset indicatorを使う。
- グレーの塗りは主に無効状態や控えめな補助面に使う。選択や主要操作のアクセントとして大きく灰色に塗らない。switchの状態表現まで一律に白くしない。
- 見出しアイコンは白背景・無彩色のアイコン・薄い枠。接続先アイコンや説明枠も白〜ごく薄いグレーを基調とする。
- 見出しアイコンと選択中タブの下線は無彩色を保つ。青いアイコンと青い下線は試した後に戻したため、装飾の差し色として再導入しない。下線は既存の2pxを維持する。
- 現行実装には控えめな無彩色の影がある。影の是非について新たなユーザー指定はなく、Popの「影なし」をNeutralへ広げない。
- 警告・エラー等の意味色は残す。「無彩色」は安全に関わる情報や状態の区別を消す意図ではない。
- focusと選択の輪郭は識別可能にし、白い入力・キー・浮動メニューを背景に同化させない。

## 書体

既存のInter/system系を使う。本文・説明・見出し・ボタン・ロゴにPopの丸ゴシックを残さない。入力・キー刻印・コードは既存の指定を維持する。
